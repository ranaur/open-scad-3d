# 3D counter

1) Fazer um cilindro de 3mm de altura x 20 mm de diâmetro com um furo de 3.9 ou 4.9 mm no centro. Na lateral gravar os números de 0 a 9.

Ao invés de cilindro, pode-se fazezr um eneágono ou colocar um "furo" entre os números.

Além disso fazer uma capa de 25 mm de diâmetro, 2mm de espessura (dando um espaço interno de 20,5 mm. Um dos lados fica aberto (para ver os números). No centro parte uma haste de 4/5 mm (ou um pouco menos) para espetar os cilindros com os números. A altura é múltipla de 3mm (altura dos cilindros). Coloca-se um pequeno calombo para travar o número (mas deixa ele mole para poder mover o número

Por fim, faz a tampa inferior, com um furo um pouco menor e um encaixe. A haste tem 3mm a mais com um encaixe.
